# Recommended AI Workflow

For each prompt:

1. Generate code.
2. Run the app.
3. Fix compilation errors.
4. Commit to Git.
5. Move to the next prompt.

Use a Git workflow like:

```bash
git checkout -b auth-module
git commit -m "Authentication completed"

git checkout -b student-module
git commit -m "Student management completed"
```

This way, if an AI tool breaks something, you can roll back to the last working module instead of rebuilding the entire project.
